A single funny line for the [One-Line Laugh-Off](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae) bounty on make.fun. The program writes exactly one joke to `/output/entry.txt` — no setup notes, no explanation.

## Entry

> My calendar invited me to my own funeral, so I RSVP'd 'maybe' — I still hate committing to things.

## Run

```sh
node main.ts
```

It writes the joke (98 characters, within the 1–200 gate) to `/output/entry.txt`, deterministically — the same bytes on every run.
